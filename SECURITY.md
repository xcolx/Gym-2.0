# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately instead, either

- through GitHub: [Report a vulnerability](https://github.com/xcolx/Gym-2.0/security/advisories/new) on the
  Security tab of the repository, or
- by email to [security@colinrueegg.com](mailto:security@colinrueegg.com).

Describe the problem, how to reproduce it and what an attacker could do with it. You'll get an answer within a few
days. Please give some time to fix the issue before you disclose it.

## Supported versions

Only the current version is supported: the hosted web app at [gym2.app](https://gym2.app), the latest iOS app in the
App Store and the `main` branch of this repository.
